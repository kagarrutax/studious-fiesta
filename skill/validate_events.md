# Validate Events Skill

## Instrucciones para el Agente IA

1. Lee `spec/00_project_spec.md` y `spec/13_events_spec.md`.
2. Revisa API/modelos/UI de eventos.
3. Implementa faltantes (CRUD, RSVP, attendees, stats snippet).

5. Ejecuta `skill/security_review.md`.
6. Reporta al orquestador.
