# Run Tests Skill

## Instrucciones para el Agente IA

1. Ingresa a la carpeta `backend/`.
2. Asegúrate de tener las dependencias de prueba (ej. `pytest`).
3. Ejecuta el suite de pruebas: `pytest tests/`.
4. Si encuentras errores, identifica el log y propón la corrección.
5. Si alguna prueba falla, DETENTE; no procedas con otras tareas.
6. Entrégale al orquestador el resultado de los tests.
