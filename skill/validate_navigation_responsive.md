# Validate Navigation & Responsive Skill

## Instrucciones para el Agente IA

1. Lee `spec/00_project_spec.md`.
2. Lee `spec/07_navigation_responsive_spec.md`.
3. Analiza `App.jsx`, `Navbar.jsx` y las configuraciones de Tailwind.
4. Revisa si el enrutamiento está protegido y las transiciones funcionan.
5. Determina si faltan reglas responsive (como menú hamburguesa).
6. Implementa clases de Tailwind necesarias para solventarlo.
7. Al no haber unit tests profundos de UI, valida el árbol de componentes (o pruebas de renderizado si existen). Detente si hay fallos.
8. Revisa si rutas privadas impiden renderizar el contenido sin JWT.
9. Valida los criterios de aceptación.
10. Documenta las modificaciones de UI.
