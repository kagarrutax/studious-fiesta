# Validate Profile Skill

## Instrucciones para el Agente IA

1. Lee `spec/00_project_spec.md`.
2. Lee `spec/02_profile_spec.md`.
3. Analiza el código en `backend/app/routers/users.py` y las vistas de perfil en frontend.
4. Identifica si el sistema de obtención de perfiles y despliegue de datos funciona según la spec.
5. Determina qué falta según los criterios de aceptación.
6. Implementa lo necesario sin sobreescribir funcionalidades existentes.
7. Ejecuta tests pertinentes (Backend). Si fallan, detente.
8. Ejecuta revisión de seguridad para validar que no se expongan datos sensibles (como hashes de passwords).
9. Verifica que los criterios de aceptación se cumplan íntegramente.
10. Genera un reporte documentando estado y modificaciones.
