# Validate Mobile Parity

1. Lee `spec/18_mobile_parity_spec.md` y los specs de cada dominio.
2. Verifica navegación y protección de rutas en Expo Router.
3. Prueba REST inicial y actualización WebSocket para chat/avisos.
4. Comprueba el modal **Actualizar** con una versión remota superior y con `mandatory` true/false.
5. Ejecuta chequeo TypeScript y export web de Expo.
6. Smoke Android de los flujos indicados en la spec.
7. Revisa que no se filtren token, email privado ni secretos.
8. Genera APK preview solo cuando todo esté verde.
